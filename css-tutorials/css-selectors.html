There are 3 Main types of Selectors in CSS

  1. Tag Selector
  2. Id Selector
  3. Class Selector

CSS Selectors

CSS Selectors are used to select any HTML element for applying the styles on that element.

1. Tag Selector

Tag selector is used to apply the style on any HTML element based on the tag name.

Following is the syntax to apply tag selector

        tagname{
            property 1 : value;
            property 2 : value;
            ...
            property N : value;
        }

2. Id Selector

Id selector is used to apply CSS on any specific element with a unique ID.

Syntax to apply id selector css 

        #element_id{
            property 1 : value;
            property 2 : value;
            ...
            property N : value;
        }

Class Selector

Class selector is used to apply common css on not all but selected elements
